# Student Management System

## 📌 Project Description

The Student Management System is a simple Python project developed using a Dictionary.
It allows users to add, view, search, update, delete student records and calculate student grades.

This project is designed to demonstrate the use of Python dictionaries, functions, conditional statements, loops, and user input.

---

## 🎯 Objectives

- To store student information using Python Dictionary.
- To add new student records.
- To view all student records.
- To search for a student using Student ID.
- To update student information.
- To delete student records.
- To calculate and display student grades.

---

## 🛠️ Technologies Used

- Python
- Dictionary
- Functions
- Conditional Statements
- Loops
- User Input

---

## 📋 Features

### 1. Add Student

The user can enter:

- Student ID
- Name
- Age
- Course
- Marks

The information is stored in a Python dictionary.

### 2. View All Students

Displays all the student records stored in the dictionary.

### 3. Search Student

The user can search for a student using the Student ID.

### 4. Update Student

Allows the user to update:

- Name
- Age
- Course
- Marks

### 5. Delete Student

Allows the user to delete a student record using Student ID.

### 6. Calculate/Display Grade

The system calculates the grade based on the student's marks.

| Marks | Grade |
|-------|-------|
| 90 - 100 | A+ |
| 80 - 89 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| Below 50 | F |

### 7. Exit

The user can exit the program by selecting option 7.
